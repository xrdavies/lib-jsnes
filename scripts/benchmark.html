lib-jsnes browser benchmark

Run npm test, then serve the repository over HTTP. This page uses the same synthetic ROM and benchmark as node scripts/benchmark.mjs. No game file is required.

The check compares 240 frames of CPU registers, cycles, pixels and PCM before timing five alternating rounds (60 warmup frames and 180 measured frames per core). Timings include emulation and audio drains. Loading, display, RGBA conversion, audio playback and parity checks are excluded.

Keep this tab visible and avoid other intensive work. The page may briefly pause while measuring. A WASM speedup above 1 means WASM was faster on this run.
